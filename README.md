# MANACO Landing Page

## Descripción del Proyecto
Este proyecto corresponde al **Primer Examen Parcial de Tecnologías de Internet**, donde se implementa una landing page responsive para la empresa **MANACO**.

## Objetivo
- Practicar HTML5 semántico.
- Aplicar accesibilidad (a11y).
- Integrar SEO básico.
- Crear diseño responsive (desktop + mobile).
- Publicar en GitHub Pages.

## Características del Proyecto
- Diseño responsive (mobile-first)
- Estructura semántica HTML5
- Enfoque en accesibilidad (a11y)
- Optimización SEO
- Desplegado en GitHub Pages

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript
- GitHub Pages
